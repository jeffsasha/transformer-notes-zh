# 03｜多头注意力：不同的头究竟在学习什么？

> 阅读目标：理解多头注意力的严格定义、"参数量真相"，以及"不同的头学不同的东西"这一说法成立的证据与边界。
>
> 前置知识：第 02 篇的单头缩放点积注意力公式；矩阵乘法；softmax 的基本性质。

## 1. 问题：一个头为什么不够？

先从直觉出发。单头注意力一次只能回答一种"加权平均"的问题：给定一个 query，它用一套打分规则决定"看谁、看多少"，然后把所有 value 按权重混合成一个向量。

但一个句子同时承载多层关系：主谓、修饰、指代、位置邻近……一个头一次只能交出一份"注意力分配方案"。如果模型想同时追踪"谁是主语"和"代词指代谁"，一个头就捉襟见肘。

多头注意力的直觉是：**派 $`h`$ 个侦察员，每人带着不同的"问题清单"独立扫描句子，最后把他们的报告拼接、混合成一份。**

> 结论性质声明：以上是直觉，不是证明。它只说明"机制上允许不同"，不保证"训练后真分工"。"不同的头究竟学到了什么"是第 4 节的实证问题，本节只解决"为什么可能不同"。

## 2. 严格定义：公式、维度与流程

采用与第 01、02 篇一致的**列向量**记法。输入为 $`x_p \in \mathbb{R}^{d_{\text{model}}}`$。

第 $`i`$ 个头（$`i=1,\dots,h`$）拥有**自己独立**的投影矩阵：

```math
q_{p,i}=W_i^Q x_p,\qquad k_{t,i}=W_i^K x_t,\qquad v_{t,i}=W_i^V x_t
```

```math
W_i^Q, W_i^K \in \mathbb{R}^{d_k \times d_{\text{model}}},\qquad
W_i^V \in \mathbb{R}^{d_v \times d_{\text{model}}}
```

每个头内部，做的正是第 02 篇的单头缩放点积注意力，原样复用：

```math
a_{pt,i}=\mathrm{softmax}_t\left(\frac{q_{p,i}^\top k_{t,i}}{\sqrt{d_k}}\right),\qquad
\mathrm{head}_{p,i}=\sum_t a_{pt,i}\,v_{t,i}\in\mathbb{R}^{d_v}
```

最后把 $`h`$ 个头的输出拼接起来，经输出投影 $`W^O`$ 混合：

```math
y_p = W^O\begin{bmatrix}\mathrm{head}_{p,1}\\ \vdots\\ \mathrm{head}_{p,h}\end{bmatrix},
\qquad W^O\in\mathbb{R}^{d_{\text{model}}\times hd_v}
```

原论文（Vaswani et al., 2017，"Attention Is All You Need"）的取值为 $`d_{\text{model}}=512`$，$`h=8`$，$`d_k=d_v=d_{\text{model}}/h=64`$。

~~~mermaid
flowchart LR
    X["输入 x_p"] --> Q1["头1: W₁ᴽ,W₁ᴷ,W₁ⱽ"]
    X --> Q2["头2: W₂ᴽ,W₂ᴷ,W₂ⱽ"]
    X --> QH["头h: Wₕᴽ,Wₕᴷ,Wₕⱽ"]
    Q1 --> A1["注意力₁ → head₁"]
    Q2 --> A2["注意力₂ → head₂"]
    QH --> AH["注意力ₕ → headₕ"]
    A1 --> C["拼接"]
    A2 --> C
    AH --> C
    C --> O["Wᴼ 混合 → y_p"]
~~~

| 符号 | 维度 | 含义 |
| --- | --- | --- |
| $`d_{\text{model}}`$ | 512（原论文） | 模型主干维度 |
| $`h`$ | 8（原论文） | 头数 |
| $`d_k, d_v`$ | $`d_{\text{model}}/h=64`$ | 单个头的 query/key/value 维度 |
| $`W_i^Q, W_i^K, W_i^V`$ | 见上式 | 第 $`i`$ 个头专属的投影矩阵 |
| $`W^O`$ | $`d_{\text{model}}\times hd_v`$ | 跨头的输出混合矩阵 |

## 3. 核心洞察：多头没有增加参数，它在重组计算

这是一个值得亲手验算的结论。

**参数量**（严格推导）。每个头的 Q 投影有 $`d_k \times d_{\text{model}}`$ 个参数；$`h`$ 个头共 $`h\cdot d_k\cdot d_{\text{model}} = d_{\text{model}}^2`$ 个（因为 $`d_k=d_{\text{model}}/h`$，$`h`$ 被约掉了）。K、V 同理各 $`d_{\text{model}}^2`$。$`W^O`$ 是 $`d_{\text{model}}\times hd_v = d_{\text{model}}\times d_{\text{model}}`$，也是 $`d_{\text{model}}^2`$。总计：

```math
\text{多头总参数量} = 4\,d_{\text{model}}^2
```

而一个"大头"（$`d_k=d_v=d_{\text{model}}`$ 的单头注意力）：Q、K、V 投影各 $`d_{\text{model}}^2`$，输出投影 $`d_{\text{model}}^2`$，总计同样是 $`4d_{\text{model}}^2`$。**两者参数量完全相同。**

**计算量**也相同：打分矩阵每头 $`O(n^2 d_k)`$，$`h`$ 头共 $`O(n^2 d_{\text{model}})`$，与单大头一致。

那么多头的优势从何而来？在于**把一次高维注意力，拆成 $`h`$ 次低维子空间上的并行注意力**：

- 单大头：一个 query 只能产生**一份**注意力权重分布。想同时关注"主语"和"宾语"？一份权重里两者必须分这 100% 的注意力质量。
- 多头：一个 query 产生 $`h`$ 份独立的权重分布，每份可以专注一种关系，最后由 $`W^O`$ 组合。

为什么不同的头"能"学得不一样？看打分公式的展开：

```math
q_{p,i}^\top k_{t,i} = x_p^\top \underbrace{(W_i^Q)^\top W_i^K}_{A_i} x_t
```

每个头有自己专属的"匹配度量" $`A_i$`。不同的头 → 不同的 $`A_i`$ → **同一对 token 在不同头下可以有完全不同的匹配分数** → 不同的权重分布。直觉上，每个头学会"一种提问方式"（query 子空间）配"一种答案来源"（key 子空间）。

> 适用边界：以上是机制层面的"可能性"论证。参数量相同不代表表达能力相同——$`h`$ 套独立的匹配度量确实比 1 套更灵活，但"头是否真分工"取决于数据与优化，这是下一节的实证问题。

## 4. 实证：头究竟学到了什么

"不同的头学不同的东西"不是设计出来的，是**训练后观察到的涌现现象**。证据主要来自对已训练模型的注意力分析，这里以 BERT-base（12 层 × 12 头）为例（Clark et al., 2019，"What Does BERT Look At?"）。

| 头（层-头） | 观察到的行为 | 对应句法关系的准确率 |
| --- | --- | --- |
| 8-10 | 动词 → 其直接宾语 | 86.8%（dobj） |
| 8-11 | 限定词 → 其修饰的名词 | 94.3%（det） |
| 4-10 | 被动助动词 → 所修饰的动词 | 82.5%（auxpass） |
| 9-6 | 介词 → 其宾语 | 76.3%（pobj） |
| 7-6 | 物主代词 / 's → 名词短语中心词 | 80.5%（poss） |
| 5-4 | 指代词 → 其先行词 | 65.1%（共指消解） |

测量方法（了解其局限很重要）：对每个词，看该头注意力权重最大的目标词，检查它是否恰好是该词在依存句法中的"头词"；准确率即猜中的比例。简单基线（如"猜左边第一个词"）只有约 40%–70%，所以上表数字显著高于偶然——**自监督训练在没有任何句法标注的情况下，涌现出了句法敏感的头**。

除上表外，还反复观察到几类"通用工种"的头：

- **位置头**：只关注前一个 / 后一个 token，不看内容——纯粹的位置偏移功能。
- **"退路"头**：当头的专职功能不适用时，把权重堆到 [SEP] 等分隔符上。Clark et al. 称之为 no-op：这不是"在关注分隔符的语义"，而是"无处可去时的默认落点"（后来的 attention sink 讨论延续了这一观察）。
- **同层头行为趋同**：用 Jensen–Shannon 散度对头聚类发现，同一层的头彼此往往相似——分工主要发生在"层之间"和"少数专职头"上，而非"每个头各管一摊"。
- **Induction head**（Anthropic, 2022，对 GPT-2 类解码器模型）：当序列出现 `[A][B]…[A]` 模式时，从第二个 A 回望第一个 A 紧跟的 B，抬高 B 成为下一个 token 的概率。这是**上下文学习（in-context learning）**的关键机制之一，由"前一 token 头 + 归纳头"两级组合实现。
- **层级趋势**（多篇分析的共识，但需按具体模型验证）：浅层头偏局部、偏句法；深层头偏长距离、偏语义。

**必须打的预防针**——严格区分"观察"与"因果"：

上表是"注意力权重与句法关系的相关性"，**不是**"模型靠这个头做决策"的因果证据。Jain & Wallace（2019，"Attention is not Explanation"）指出：可以构造出权重分布完全不同、但模型输出相同的注意力模型——高权重不等于决定性作用。

所以准确的表述是"训练涌现出了句法敏感的头"，而不是"模型用 8-10 头来理解宾语"。前者是本节证据支持的结论，后者需要因果干预实验（如剪枝 / 替换该头后看任务指标变化）才能下断言。

## 5. 数值示例：两个头，两种权重分布

设 $`d_{\text{model}}=4`$，$`h=2`$，$`d_k=d_v=2`$。三个 token 的输入向量（列向量）：

```math
x_1=\begin{bmatrix}1\\0\\1\\0\end{bmatrix},\quad
x_2=\begin{bmatrix}0\\1\\0\\1\end{bmatrix},\quad
x_3=\begin{bmatrix}1\\1\\0\\0\end{bmatrix}
```

头 1 只看前两维，头 2 只看后两维（极简的"不同子空间"设定）：

```math
W_1^Q=W_1^K=W_1^V=\begin{bmatrix}1&0&0&0\\0&1&0&0\end{bmatrix},
\qquad
W_2^Q=W_2^K=W_2^V=\begin{bmatrix}0&0&1&0\\0&0&0&1\end{bmatrix}
```

以 $`x_1`$ 为 query，计算它对三个 token 的打分（已除以 $`\sqrt{d_k}=\sqrt{2}`$）：

- **头 1**：$`q=[1,0]^\top`$，key 投影为 $`[1,0],[0,1],[1,1]`$，打分 $`[0.707, 0, 0.707]`$，softmax 后权重为 $`[0.401, 0.198, 0.401]`$——在 token 1 和 token 3 之间犹豫。
- **头 2**：$`q=[1,0]^\top`$，key 投影为 $`[1,0],[0,1],[0,0]`$，打分 $`[0.707, 0, 0]`$，softmax 后权重为 $`[0.504, 0.248, 0.248]`$——集中看 token 1。

**同一个 query、同一组 token，只因投影子空间不同，两个头给出了不同的权重分布。**继续算输出（此处 $`v`$ 投影与 $`q,k`$ 取同一矩阵）：

```math
\mathrm{head}_1 = 0.401\begin{bmatrix}1\\0\end{bmatrix}
+0.198\begin{bmatrix}0\\1\end{bmatrix}
+0.401\begin{bmatrix}1\\1\end{bmatrix}
=\begin{bmatrix}0.802\\0.599\end{bmatrix}
```

```math
\mathrm{head}_2 = 0.504\begin{bmatrix}1\\0\end{bmatrix}
+0.248\begin{bmatrix}0\\1\end{bmatrix}
+0.248\begin{bmatrix}0\\0\end{bmatrix}
=\begin{bmatrix}0.504\\0.248\end{bmatrix}
```

拼接得 $`[0.802, 0.599, 0.504, 0.248]^\top`$，再经 $`W^O`$（此处取单位阵示意）即为最终输出。现实中 $`W^O`$ 是可学习的：它决定每个头的"报告"占多大分量，以及跨头如何组合。

本例的要点：**分工的"原材料"是不同的投影矩阵；分工的"成品"（每个头到底关注什么）是训练学出来的。**示例中我们手工指定了"头 1 看前两维"，真实训练中 $`W_i`$ 由梯度决定。

## 6. 常见误区

- "头越多越好"——错。固定 $`d_{\text{model}}`$ 时头数越多，每个头的 $`d_k`$ 越小，单个头能编码的关系越受限。Michel et al.（2019）证明：测试时剪掉 BERT 的大部分头，任务精度几乎不降——**冗余是常态，不是例外**（这也引出了第 09 篇的 GQA/MQA：既然很多头冗余，能否共享参数）。
- "每个头都有清晰的语言学分工"——错。分工是涌现的、统计的：第 4 节的表是"表现最好的头"，不是"每个头"；很多头只做位置偏移或"退到 [SEP]"这类通用杂务。
- "注意力权重高 = 这个 token 决定了输出"——不严谨。见第 4 节末的预防针：权重是相关性证据，不是因果解释；要做因果断言需要干预实验。
- "多头注意力的参数量是单头的 $`h`$ 倍"——错。参数量与"一个维度为 $`d_{\text{model}}`$ 的大头"完全相同，都是 $`4d_{\text{model}}^2`$；多的是"并行的子空间"，不是参数。
- "多头就是把 $`h`$ 个注意力的结果取平均"——错。是拼接后经 $`W^O`$ 做**可学习的线性混合**，$`W^O`$ 可以给不同头不同权重，也可以做跨头的线性组合；平均只是它的一个特例。

## 7. 自测题

1. $`d_{\text{model}}=512`$、$`h=8`$ 时，每个头的 $`d_k`$ 是多少？多头注意力的总参数量是多少？
   - 答：$`d_k=512/8=64`$；总参数量 $`4\times 512^2=1{,}048{,}576`$。
2. 参数量既然与单大头相同，多头注意力的表达优势从何而来？
   - 答：来自"多个低维子空间上的并行打分 + 可学习的跨头混合"。单大头只有一个匹配度量 $`A`$，一份权重分布；多头有 $`h`$ 套 $`A_i`$，同一对 token 在不同头下可以有不同的匹配分数，再由 $`W^O`$ 组合——表示更灵活，而不是参数更多。
3. BERT 的 8-10 头以 86.8% 的准确率对应哪种句法关系？这个数字是怎么测出来的？
   - 答：dobj（动词 → 直接宾语）。测量方法：对每个动词，看该头权重最大的目标词是否为其直接宾语，统计猜中比例；简单基线只有约 40%，86.8% 显著高于偶然。
4. 某头把大部分注意力放在 [SEP] 上，能否断定"它在关注分隔符的语义"？
   - 答：不能。这是已知的 no-op /"退路"行为：头的专职功能不适用时，权重退到分隔符上——这是"无处可去"，不是"语义关注"。

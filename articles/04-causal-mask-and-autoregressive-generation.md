# 04｜因果 mask 与自回归生成

> 阅读目标：理解因果 mask 的严格定义、它为什么必须加在 softmax 之前，以及它如何把"并行训练"和"逐词生成"统一成同一套计算。
>
> 前置知识：第 02 篇的缩放点积注意力公式 $`a_{pt}=\mathrm{softmax}_t(q_p^\top k_t/\sqrt{d_k})`$；softmax 定义；条件概率的链式法则。

## 1. 问题：生成时"不能看未来"，训练时却能看到整句？

先从直觉出发。语言模型的生成方式叫**自回归（autoregressive）**：一次只预测下一个词，把预测结果接回输入，再预测下下个词。数学上，它把整句的概率拆成一连串条件概率的乘积：

```math
P(x_1,\dots,x_T) = \prod_{t=1}^{T} P(x_t \mid x_{<t}),\qquad x_{<t}=(x_1,\dots,x_{t-1})
```

生成第 $`t`$ 个词时，模型手里只有 $`x_1,\dots,x_{t-1}`$——**未来词根本不存在**。

但训练时我们把整句话一次性喂给 Transformer：位置 $`p`$ 的 query 会和所有位置 $`t=1,\dots,n`$ 的 key 算打分，包括 $`t>p`$ 的"未来"词。如果放任不管，模型在训练时就能偷看到它要预测的词——训练和推理的"视野"不一致，这就是**信息泄漏**。

因果 mask 的直觉就是：**给每个 query 戴上只能看左边的眼罩**，在打分阶段就把未来位置抹掉。

> 结论性质声明：以上"眼罩"是直觉。第 2 节给出 mask 的严格定义与数学保证；"训练和推理视野一致为什么重要"是第 3 节的等价性论证。

## 2. 严格定义：mask 矩阵与带 mask 的注意力公式

沿用第 01–03 篇的**列向量**记法。定义因果 mask 矩阵 $`M \in \mathbb{R}^{n\times n}`$（$`n`$ 为序列长度，$`p`$ 是 query 位置、$`t`$ 是 key 位置）：

```math
M_{pt} = \begin{cases} 0 & t \le p \\ -\infty & t > p \end{cases}
```

带 mask 的缩放点积注意力，就是在第 02 篇公式的 logits 上逐元素加上 $`M`$：

```math
a_{pt} = \mathrm{softmax}_t\left(\frac{q_p^\top k_t}{\sqrt{d_k}} + M_{pt}\right),\qquad \hat{x}_p = \sum_t a_{pt}\,v_t
```

**为什么 $`-\infty`$ 能"抹掉"未来（严格推导）。** Softmax 的定义是 $`\mathrm{softmax}(z)_t = e^{z_t}/\sum_j e^{z_j}`$。对 $`t>p`$ 的位置，logit 是 $`z_t + (-\infty)`$，而 $`e^{-\infty}\to 0`$。取极限写清楚：

```math
\lim_{c\to-\infty}\ \mathrm{softmax}(z_1,\dots,z_p,z_{p+1}+c,\dots,z_n+c)_t = 0 \quad (t > p)
```

未来位置的权重被精确地压成 0，剩下的 $`p`$ 个位置权重重新归一化，和仍为 1。mask 矩阵长这样（$`n=4`$，行 $`p`$ 为 query，列 $`t`$ 为 key）：

|     | t=1 | t=2 | t=3 | t=4 |
|-----|-----|-----|-----|-----|
| p=1 | 0   | −∞  | −∞  | −∞  |
| p=2 | 0   | 0   | −∞  | −∞  |
| p=3 | 0   | 0   | 0   | −∞  |
| p=4 | 0   | 0   | 0   | 0   |

下三角（含对角线）可见——这就是"因果"之名的由来：**原因（过去）可以影响结果（现在），反之不行**。

**梯度视角：mask 是硬约束，不是建议（严格推导）。** 对 $`t>p`$ 有 $`a_{pt}\equiv 0`$ 恒成立。Softmax 的雅可比是 $`\partial a_{pt}/\partial s_{pj} = a_{pt}(\delta_{tj}-a_{pj})`$（$`s_{pj}`$ 为加 mask 前的 logit）。当 $`a_{pt}=0`$ 时，该行对未来 key/value 的梯度恒为 0。结论：**未来 token 的参数梯度在这一层被彻底切断**——这是"无信息泄漏"的数学保证。

> 适用条件：以上保证成立的前提是 mask 加在 softmax **之前**的 logits 上。加在之后会破坏保证，见第 5 节误区 1。

~~~mermaid
flowchart LR
    S["原始打分 q_p^⊤k_t/√d_k"] --> ADD["+ mask M（未来位置 → −∞）"]
    ADD --> SM["softmax（未来权重 = 0，重归一化）"]
    SM --> OUT["加权求和 ∑ a_pt v_t（只混合过去）"]
~~~

## 3. 核心洞察：mask 让"并行训练"等价于"顺序生成"

训练时，输入整句 $`x_1,\dots,x_n`$，一次前向同时得到所有位置的输出 $`\hat{x}_1,\dots,\hat{x}_n`$。因为有 mask，位置 $`p`$ 的输出**只依赖** $`x_{\le p}=(x_1,\dots,x_p)`$。训练目标是让每个位置预测下一个词（这就是 **teacher forcing**：训练时把标准答案的前缀直接喂进去当条件）：

```math
\mathcal{L} = -\sum_{p=1}^{n-1} \log P(x_{p+1}\mid x_{\le p})
```

**关键等价性（严格推导）。** 位置 $`p`$ 的计算只用到 $`x_{\le p}`$，与"先顺序生成到第 $`p`$ 步再算"的结果逐元素相同（给定相同参数、确定性前向）。因此：

> **一次并行前向 ＝ $`n`$ 次顺序前向的打包。**

训练复杂度从 $`O(n)`$ 次前向降为 $`O(1)`$ 次前向——这正是 GPT 系列能大规模训练的计算基础。没有因果 mask，这个并行化就不成立：要么泄漏未来（作弊），要么退回逐词训练（太慢）。

> 结论性质区分：
> - "并行前向与顺序前向逐元素相同"是**严格结论**（mask 的数学保证）。
> - "这样训练出的模型生成质量好"是**需实验验证的结论**——训练时每一步都拿到标准前缀，生成时却只能靠自己的历史输出，这种差异叫 exposure bias，是第 10 篇要讨论的话题。

训练 vs 生成的对照：

|  | 训练（并行） | 生成（顺序） |
|---|---|---|
| 输入 | 整句 $`x_1,\dots,x_n`$ 一次喂入 | 已生成的 $`x_1,\dots,x_t`$，逐词追加 |
| mask | 因果 mask 保证位置 $`p`$ 只看 $`x_{\le p}`$ | 天然只看已生成部分（未来不存在） |
| 输出 | 所有位置同时预测下一个词 | 每次只采样 $`x_{t+1}`$ |
| 本质 | $`n`$ 个"给定前缀预测下词"任务的打包 | 同一个任务逐个执行 |

## 4. 数值示例：亲手算一次 mask

句子"猫 / 追 / 老鼠 / 跑"，$`n=4`$。假设位置 $`p=3`$（"老鼠"）的原始打分（已除过 $`\sqrt{d_k}`$）为：

```math
s = [\,1.0,\;\; 2.0,\;\; 0.5,\;\; 3.0\,]\quad\text{（依次对"猫、追、老鼠、跑"）}
```

不加 mask 的话，模型最"关注"的是"跑"（3.0 分）——而"跑"恰恰是它在这个位置要预测的词，典型的作弊。

加因果 mask：$`s' = [\,1.0,\;\; 2.0,\;\; 0.5,\;\; -\infty\,]`$。

算 softmax：$`e^{1.0}=2.718`$，$`e^{2.0}=7.389`$，$`e^{0.5}=1.649`$，$`e^{-\infty}=0`$；分母和 $`=11.756`$。

```math
a = [\,0.231,\;\; 0.629,\;\; 0.140,\;\; 0.000\,]
```

三项检验：① 和 $`=1.000`$ ✓（仍是合法的概率分布）；② 未来词"跑"的权重恰为 0 ✓；③ "追"（0.629）成为主导——模型只能基于"猫追老鼠"来预测下一个词，这正是我们想要的。

每个位置的可见集（$`n=4`$）：

| 位置 p | 可见 token | 正在预测 |
|---|---|---|
| 1（猫） | {猫} | 第 2 个词 |
| 2（追） | {猫，追} | 第 3 个词 |
| 3（老鼠） | {猫，追，老鼠} | 第 4 个词 |
| 4（跑） | {猫，追，老鼠，跑} | （句末，无监督信号） |

## 5. 常见误区

**误区 1：mask 加在 softmax 之后也行，反正都是置零。**

纠正：不行，两处致命差别。第一，softmax 之后再置零，权重和小于 1，不再是概率分布，后续加权求和的尺度全错。第二更本质：softmax 的分母求和时已经"看过"了未来的 logit——未来的 key 参与了归一化，信息已经泄漏进每一个权重里。**mask 必须加在 logits 上、softmax 之前**，这是第 2 节数学保证成立的前提条件。

**误区 2：因果 mask 就是一种 dropout。**

纠正：不是。Dropout 是训练时的随机正则，推理时关闭；mask 是确定性的结构约束，训练和推理都要生效。Dropout 随机"失明"，mask 永久"只能看左边"——目的完全不同。

**误区 3：BERT 也用因果 mask。**

纠正：不用。BERT 是编码器，训练目标是掩码语言模型（完形填空），需要**双向**上下文，用的是 padding mask（遮掉填充位），不是因果 mask。因果 mask 是 Decoder-only 架构（GPT 系列）和 Decoder 自注意力的标配。注意 Decoder 的 **cross-attention**（query 来自 Decoder、key/value 来自 Encoder 输出）**不需要**因果 mask——Encoder 的输出在解码开始前已经全部算好，不存在"未来"可言。

**误区 4：代码里真的写 $`-\infty`$ 吗？**

纠正：概念上是 $`-\infty`$；实现上常用很大的负数。$`e^{-10^9}`$ 下溢为 0.0，效果与 $`-\infty`$ 等价。但要注意精度陷阱：fp16 下 -1e9 本身会溢出，实践中常用 `torch.finfo(dtype).min` 或 `masked_fill(..., float('-inf'))`。这是工程细节，不改变数学结论。

## 6. 自测题

**Q1.** 位置 $`p`$ 的 query 在加 mask 后，softmax 分母的求和项数是多少？

<details>
<summary>答案</summary>

$`p`$ 项（$`t=1,\dots,p`$）。$`n-p`$ 个未来位置的 $`e^{-\infty}=0`$，对分母没有贡献。
</details>

**Q2.** 如果把 mask 矩阵换成全零矩阵（即不 mask），训练一个"预测下一个词"的模型会发生什么？

<details>
<summary>答案</summary>

位置 $`p`$ 能直接看到 $`x_{p+1}`$——模型要预测的词就躺在输入里。最优策略是把注意力权重全压在 $`t=p+1`$ 上"抄答案"，训练损失趋近于 0。但生成时没有未来可抄，模型完全失效。这就是信息泄漏最直观的演示：训练指标越好，真实能力越差。
</details>

**Q3.** Decoder 的 cross-attention 里，query 来自 Decoder、key/value 来自 Encoder 的输出，需要加因果 mask 吗？为什么？

<details>
<summary>答案</summary>

不需要。因果约束只针对"随时间逐步产生"的序列。Encoder 的输出在解码开始前已经全部计算完毕，对 Decoder 来说不存在"未来"。注意 Decoder **内部**的自注意力仍然需要因果 mask。
</details>

**Q4.** 生成第 $`t`$ 个词时，KV Cache（第 08 篇）能复用之前算好的 key/value。这一结论依赖因果 mask 的哪条性质？

<details>
<summary>答案</summary>

依赖"过去不受未来影响"：位置 $`p\le t`$ 的 key/value 只依赖 $`x_{\le p}`$，当序列从长度 $`t`$ 延长到 $`t+1`$ 时，它们的值不变，所以可以缓存复用。如果没有因果 mask，每新增一个词，全句每个位置的表示都会变，缓存就失效了。
</details>

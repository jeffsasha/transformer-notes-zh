# 02｜缩放点积注意力：为什么除以 √d_k

> 阅读目标：理解缩放因子 $`\sqrt{d_k}`$ 的作用——它解决什么问题，不解决什么问题。
>
> 前置知识：第 01 篇的注意力打分公式；均值、方差；softmax 的基本性质。

## 1. 问题：这个除法在干什么？

单头注意力的打分公式为：

```math
s_{pt}=\frac{q_p^\top k_t}{\sqrt{d_k}},\qquad q_p,k_t\in\mathbb R^{d_k}
```

初见会有三个疑问：为什么要除？为什么除以 $`\sqrt{d_k}`$ 而不是 $`d_k`$ 或别的数？不除会怎样？

本篇的答案可以先行一句话概括：**点积的波动幅度随维度 $`d_k`$ 增长，除以 $`\sqrt{d_k}`$ 把它拉回与维度无关的量级，防止 softmax 进入梯度消失的饱和区。**

## 2. 直觉：维度越高，点积的波动越大

点积是 $`d_k`$ 个乘积之和：

```math
q^\top k=\sum_{i=1}^{d_k}q_ik_i
```

把每一项 $`q_ik_i`$ 想象成一个随机数。项数越多，和的波动越大——就像抛 100 枚硬币的总分，比抛 1 枚波动大得多。

当 $`d_k=64`$ 时，两组"本该差不多"的 query/key，点积可能差出十几；$`d_k=512`$ 时，这个差距更大。波动本身不是问题，问题是它接下来要进 softmax。

## 3. 核心推导：点积的方差恰为 $`d_k`$

做一个理想化假设：$`q_i,k_i`$ 相互独立，均值为 0，方差为 1（这是随机初始化早期的合理近似）。

单项 $`q_ik_i`$ 的均值与方差：

```math
\mathbb E[q_ik_i]=\mathbb E[q_i]\mathbb E[k_i]=0
```

```math
\mathrm{Var}(q_ik_i)=\mathbb E[q_i^2]\mathbb E[k_i^2]-0=1\cdot 1=1
```

$`d_k`$ 个独立项求和，方差相加：

```math
\mathrm{Var}(q^\top k)=d_k,\qquad \mathrm{std}(q^\top k)=\sqrt{d_k}
```

于是除以 $`\sqrt{d_k}`$ 之后：

```math
\mathrm{Var}\left(\frac{q^\top k}{\sqrt{d_k}}\right)=1
```

方差回到 1，**与维度无关**。这就是 $`\sqrt{d_k}`$ 而不是 $`d_k`$ 的原因：我们要抵消的是标准差（$`\sqrt{d_k}`$），不是方差本身。

> 适用边界：独立性、单位方差都是理想化假设。真实训练中 $`q,k`$ 并不独立，方差也不恰为 1。所以 $`\sqrt{d_k}`$ 是一个"量级正确"的启发式选择，不是对真实分布的精确标准化。LayerNorm 等机制也在做同一类事情。

## 4. 为什么方差大会伤害训练：softmax 饱和

```math
\mathrm{softmax}(s)_i=\frac{e^{s_i}}{\sum_je^{s_j}}
```

当打分量级很大（比如标准差为 8）时，最大的一项在指数放大下碾压其余项，softmax 输出接近 one-hot。集中本身不是问题，问题在梯度：

```math
\frac{\partial\,\mathrm{softmax}_i}{\partial s_j}=p_i(\delta_{ij}-p_j)
```

当 $`p_i`$ 接近 0 或 1 时，上式接近 0——**梯度消失**。$`W_Q,W_K`$ 学不动，注意力模式"冻住"在接近随机初始化的样子，训练早期就失去调整能力。

除以 $`\sqrt{d_k}`$ 把打分拉回温和区间，softmax 保持"可微的犹豫"，梯度得以流动。这与"温度"概念完全一致：$`s/\sqrt{d_k}`$ 就是温度 $`T=\sqrt{d_k}`$ 的 softmax。

| | 未缩放 $`s`$ | 缩放 $`s/\sqrt{d_k}`$ |
| --- | --- | --- |
| 打分方差 | $`d_k`$ | 1（与维度无关） |
| softmax 形态（$`d_k=64`$） | 接近 one-hot | 温和分布 |
| 梯度 | 易饱和消失 | 可流动 |
| argmax（选谁） | 不变 | 不变 |

## 5. 缩放不改变什么

- **不改变排序**：除以正常数是单调变换，argmax 不变。"最该关注谁"不受影响，受影响的只是"以多大的权重犹豫"。
- **不是唯一的缩放方式**：实践中有除以 $`d_k`$、用可学习温度参数等变体。$`\sqrt{d_k}`$ 只是"方差归一"视角下的自然选择。
- 注意 $`d_k`$ 与 $`d`$ 的区别：$`d_k`$ 是**单个头**的维度（$`d_{\text{model}}/$` 头数）。多头把维度切小，本身也缓解了方差问题——但这不等于可以省略缩放。

## 6. 常见误区

- “除以 $`\sqrt{d_k}`$ 是为了让注意力权重和为 1”——错。和为 1 是 softmax 自身的性质，与缩放无关。
- “$`d_k`$ 越大越需要缩放”——结论对，原因要说准：不是"维度大"本身，而是"点积的方差随维度线性增长"。
- “缩放让模型更关注语义”——不准确。缩放只改变分布的陡峭程度，不改变"谁比谁大"；语义从哪里来，是 $`W_Q,W_K`$ 训练学出来的。

## 7. 自测题

1. 若 $`q_i,k_i`$ 独立、均值 0、方差 1，$`d_k=64`$，未缩放点积的方差是多少？缩放后呢？
   - 答：64；1。
2. 缩放是否改变 softmax 的 argmax？为什么？
   - 答：不改变。除以正常数是单调变换，不改变大小顺序。
3. 如果把 $`\sqrt{d_k}`$ 换成 $`d_k`$，会发生什么？
   - 答：打分被过度压缩，方差变为 $`1/d_k`$，softmax 接近均匀分布，区分度下降——两个方向走极端都伤害训练。
4. softmax 饱和时梯度为什么消失？
   - 答：$`\partial p_i/\partial s_j=p_i(\delta_{ij}-p_j)`$，$`p_i\to 0$ 或 $1`$ 时该式趋于 0。

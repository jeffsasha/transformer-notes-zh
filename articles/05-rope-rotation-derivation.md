# 05｜RoPE 的二维旋转推导与实现

> 阅读目标：理解 RoPE 为什么用"旋转"代替"相加"来编码位置；亲手推导旋转后的注意力打分只依赖相对位移；掌握分对旋转的实现公式。
>
> 前置知识：第 01 篇的正余弦位置编码与频率 $`\theta_i=10000^{-2i/d}`$；第 02 篇的缩放点积注意力 $`a_{mn}=\mathrm{softmax}_n(q_m^\top k_n/\sqrt{d})`$；二维旋转矩阵。

## 1. 问题：位置编码为什么要从"加一个向量"变成"转一个向量"？

第 01 篇里，位置信息是"加"进去的：$`x_m + p_m`$。加法带来一个麻烦，把打分完整展开看得最清楚：

```math
(x_m + p_m)^\top (x_n + p_n) = \underbrace{x_m^\top x_n}_{\text{纯内容}} + \underbrace{x_m^\top p_n + p_m^\top x_n}_{\text{内容–位置交叉项}} + \underbrace{p_m^\top p_n}_{\text{纯位置}}
```

四项里只有最后一项是"干净"的：对正余弦编码，$`p_m^\top p_n = \sum_i \cos\big((m-n)\theta_i\big)`$（第 01 篇的相对位移性质），确实只依赖 $`m-n`$。但中间两项交叉项把内容向量和**绝对**位置向量 $`p_n`$、$`p_m`$ 缠在了一起——"词 $`x_m`$ 在第 $`n`$ 个绝对位置旁边"这种信息混进了打分。于是打分不是相对位移的纯函数，模型必须自己从训练数据里学着"忽略"绝对位置的影响。

**为什么相对位置才是语言真正需要的（直觉）。** 决定"猫追老鼠"和"老鼠追猫"意思不同的，是"猫"和"追"的**相对**先后，而不是它们恰好在第几个绝对位置上；否定词 "not" 修饰的是它后面几个词，与整句的绝对长度无关。语言里的结构关系几乎都是相对的——绝对位置只是把句子"摆"在序列里的一个偶然选择。加法位置编码把偶然的绝对位置也喂给了模型，等于让模型在训练里自己去"发现"绝对位置不重要；RoPE 则在数学上直接保证：位置部分只贡献相对位移。

RoPE（Rotary Position Embedding，RoFormer，Su et al. 2021）的直觉是：**位置信息不应该"加"在向量上，而应该"织"进 Q 和 K 的几何变换里**。具体做法：把位置 $`m`$ 的 query 向量旋转 $`m\theta`$ 角度，位置 $`n`$ 的 key 向量旋转 $`n\theta`$ 角度。旋转是刚体运动——不改变向量长度，只改变方向。两个旋转后的向量做内积时，角度差 $`m\theta - n\theta = (m-n)\theta`$ 自然出现：

```math
(R_{m\theta}\,q_m)^\top (R_{n\theta}\,k_n) = q_m^\top\, R_{(n-m)\theta}\,k_n
```

右端只含 $`m-n`$——**相对位置是算出来的，不是加进去的**。

一个最直观的图像是**时钟指针**：把位置 $`m`$ 想象成一根指向角度 $`m\theta`$ 的分针，位置 $`n`$ 的分针指向 $`n\theta`$。两根指针的夹角是 $`(n-m)\theta`$——夹角只取决于两针的相对差，和"现在是几点"（绝对位置）无关。RoPE 就是给每个维度对装了一根"分针"，转速 $`\theta_i`$ 各不相同；注意力打分读的不是指针的绝对指向，而是两针之间的夹角。

> 结论性质声明："旋转后打分只依赖相对位移"是第 2 节的严格推导；"旋转保范数所以打分尺度稳定"是直觉（其严格部分是正交变换保范数，见第 2.1 节）。

两种位置编码的对照：

| | 加法位置编码（第 01 篇） | 旋转位置编码 RoPE（本篇） |
|---|---|---|
| 位置信息进入方式 | $`x_m + p_m`$：向量相加 | $`R_{m\theta}\,x_m`$：向量旋转 |
| 打分的结构 | 四项展开，含内容–位置交叉项 | $`q_m^\top R_{(n-m)\theta} k_n`$：相对位移的纯函数 |
| 是否改变向量长度 | 会（$`\|x_m + p_m\| \ne \|x_m\|`$） | 不会（正交变换保范数） |
| 频率 $`\theta_i`$ 的作用 | 决定正余弦波的疏密 | 决定每对维度的旋转快慢 |
| 参数量 | 0（正余弦版）或 $`n \times d`$（可学习版） | 0 |

可以这样记忆：加法是把位置"贴"在内容上，旋转是把位置"拧"进 Q、K 的相对关系里。

**RoPE 在历史上的位置（背景）。** 位置编码的演进是一条"从绝对走向相对"的路：2017 年 Transformer 用正余弦/可学习的**绝对**位置编码（加法）；2018 年 Shaw et al. 提出**相对**位置表示——为每个相对偏移学一个向量，加到 key 上，但要多存一张随距离裁剪的偏移表，多参数、多计算；2019 年 T5 把它简化成每个头、每个距离桶一个标量偏置。2021 年 Su et al. 的 RoFormer 换了思路：**不存任何位置参数，让相对位置从旋转的内积里自己"长"出来**——零新增参数、不用裁剪距离、计算只是逐元素的乘加。LLaMA、Qwen 等后来的主流大模型都采用了它。本篇只讲清它的数学与实现，不评价它是否"最优"——那是需实验验证的问题。

## 2. 二维情形的严格推导

### 2.1 旋转矩阵的三条性质

二维旋转矩阵：

```math
R(\phi) = \begin{bmatrix} \cos\phi & -\sin\phi \\ \sin\phi & \cos\phi \end{bmatrix}
```

三条性质（直接展开即可验算，这里把关键步骤写出来）：

1. **正交**：$`R(\phi)^\top R(\phi) = I`$，即 $`R(\phi)^\top = R(\phi)^{-1}`$。验算：$`R(\phi)^\top = \begin{bmatrix} \cos\phi & \sin\phi \\ -\sin\phi & \cos\phi \end{bmatrix}`$，相乘得 $`\begin{bmatrix} \cos^2\phi+\sin^2\phi & 0 \\ 0 & \sin^2\phi+\cos^2\phi \end{bmatrix} = I`$。几何含义：旋转不改变向量长度，$`\|R(\phi)x\| = \|x\|`$。
2. **逆即反向旋转**：$`R(\phi)^{-1} = R(-\phi)`$。由性质 1，$`R(\phi)^{-1} = R(\phi)^\top`$，而把 $`-\phi`$ 代入旋转矩阵定义：$`\cos(-\phi)=\cos\phi`$，$`\sin(-\phi)=-\sin\phi`$，恰好等于 $`R(\phi)^\top`$。
3. **角度可加**：$`R(\phi)R(\psi) = R(\phi+\psi)`$。左乘展开：左上角 $`\cos\phi\cos\psi - \sin\phi\sin\psi = \cos(\phi+\psi)`$，右上角 $`-\cos\phi\sin\psi - \sin\phi\cos\psi = -\sin(\phi+\psi)`$，其余两项同理——用的都是高中和角公式。

### 2.2 打分只依赖相对位移（严格推导）

定义位置编码函数 $`f(x, m) = R_{m\theta}\,x`$，其中 $`R_{m\theta} = R(m\theta)`$。对位置 $`m`$ 的 query $`q_m`$ 和位置 $`n`$ 的 key $`k_n`$：

```math
(R_{m\theta}\,q_m)^\top (R_{n\theta}\,k_n)
= q_m^\top\, R_{m\theta}^\top\, R_{n\theta}\, k_n
= q_m^\top\, R(-m\theta)\, R(n\theta)\, k_n
= q_m^\top\, R\big((n-m)\theta\big)\, k_n
```

第二步用了性质 1 和 2（$`R_{m\theta}^\top = R(-m\theta)`$），第三步用了性质 3。绝对位置 $`m, n`$ 被消掉了，剩下的只是相对位移 $`n-m`$ 的函数。记 $`\delta = (n-m)\theta`$，把坐标展开（设 $`q=(a,b)^\top`$，$`k=(c,d)^\top`$）：

```math
q^\top R(\delta)\, k = (ac+bd)\cos\delta + (bc-ad)\sin\delta
```

验算：$`R(\delta)k = (c\cos\delta - d\sin\delta,\; c\sin\delta + d\cos\delta)^\top`$，再与 $`(a,b)`$ 做内积即得上式。

**最小例子：$`d=2`$ 时亲手验证。** 取 $`q = k = (1, 0)^\top`$，$`\theta = 1`$，$`m = 2`$，$`n = 5`$：

- $`R_{2}q = (\cos 2,\; \sin 2)^\top = (-0.4161,\; 0.9093)^\top`$
- $`R_{5}k = (\cos 5,\; \sin 5)^\top = (0.2837,\; -0.9589)^\top`$

内积 $`= (-0.4161)(0.2837) + (0.9093)(-0.9589) = -0.1180 - 0.8719 = -0.9900`$。

用相对公式：$`(ac+bd)\cos\delta + (bc-ad)\sin\delta`$，其中 $`a=c=1, b=d=0, \delta=3`$，得 $`1 \cdot \cos 3 + 0 = \cos 3 \approx -0.9900`$ ✓。两种算法殊途同归——而相对公式根本不需要知道 $`m=2, n=5`$，只需要 $`\delta = 3`$。

> 适用条件：该结论成立的前提是 Q 和 K 用**同一个** $`\theta`$（同一维度对共享频率）。第 3 节会看到不同维度对用不同频率，但同一对内部频率一致——这是实现时必须遵守的配对规则。

如果违反这个条件会怎样？假设 query 用频率 $`\theta`$、key 用频率 $`2\theta`$，则 $`(R_{m\theta}q)^\top(R_{2n\theta}k) = q^\top R(2n\theta - m\theta)k`$——$`m`$ 和 $`n`$ 的系数不一样，无法合并成 $`(n-m)`$ 的函数，相对性被彻底破坏。所以"同一对维度共享频率"不是代码风格问题，而是定理成立的前提；实现时一旦配对错位，RoPE 就退化成一种奇怪的绝对位置编码。

### 2.3 为什么是旋转，而不是别的变换？

缩放会改变范数，打分的尺度随之失稳；平移（加法）就是第 01 篇的老路，会引入内容–位置交叉项。旋转是保持内积结构的最简变换：$`(Rq)^\top(Rk) = q^\top k`$ 本身不变，位置信息只通过**角度差**进入。这是 RoPE 设计的妙处——**位置编码不改变"内容相似度"的基准，只叠加一个相对位移的调制**。

为什么不用反射（镜像）？反射也是正交变换、也保范数，但它行列式为 $-1$，会翻转"手性"；更重要的是两次反射的复合才是旋转，$`R_{m\theta}`$ 随 $`m`$ 连续变化的要求（位置是连续整数，变换要随位置"转"起来）天然指向旋转群。直觉上说：位置是沿序列"走"出来的，旋转是"走"着产生的变换，反射不是。

## 3. 从二维到高维：分对旋转与多尺度频率

### 3.1 分对旋转

$`d`$ 维向量按 $`(0,1), (2,3), \dots, (d-2, d-1)`$ 配成 $`d/2`$ 对，每对独立旋转。第 $`i`$ 对用自己的频率 $`\theta_i`$：

```math
\theta_i = 10000^{-2i/d}, \qquad i = 0, 1, \dots, d/2 - 1
```

这正是第 01 篇正余弦位置编码用的那组频率——RoPE 把同一组频率从"加法"搬到了"旋转"里。位置 $`m`$ 的完整变换是分块对角矩阵：

```math
R_{\Theta,m} = \mathrm{diag}\big(R(m\theta_0),\, R(m\theta_1),\, \dots,\, R(m\theta_{d/2-1})\big)
```

高维版本的相对性同样成立（分块对角矩阵的转置与乘法逐块进行）：

```math
(R_{\Theta,m}\,q_m)^\top (R_{\Theta,n}\,k_n) = q_m^\top\, R_{\Theta,\,n-m}\, k_n
```

推导只用把第 2.2 节的步骤逐块重复一遍：$`R_{\Theta,m}^\top = \mathrm{diag}\big(R(m\theta_0)^\top, \dots\big) = \mathrm{diag}\big(R(-m\theta_0), \dots\big)`$，再与 $`R_{\Theta,n}`$ 逐块相乘，角度相减得 $`R_{\Theta,n-m}`$。打分展开成 $`d/2`$ 个二维项之和，每项都形如第 2.2 节的 $`(ac+bd)\cos((n-m)\theta_i) + (bc-ad)\sin((n-m)\theta_i)`$。

注意记号 $`R_{\Theta,n-m}`$ 的含义：它不是"位置 $`n-m`$ 的旋转矩阵"，而是把**相对位移** $`n-m`$ 当作"位置"代入同一套旋转规则——这正是相对位置编码的数学形态。

### 3.2 多尺度：快慢搭配的直觉

| 维度对 $`i`$ | $`\theta_i`$（$`d=128`$ 时） | 波长 $`2\pi/\theta_i`$ | 角色直觉 |
|---|---|---|---|
| 0 | 1 | ≈ 6.28 | 高频：转得快，对近距离位移敏感 |
| 1 | ≈ 0.866 | ≈ 7.26 | 中高频 |
| 2 | ≈ 0.750 | ≈ 8.38 | 中频 |
| 32 | 0.01 | ≈ 628 | 中低频：覆盖句子/段落级距离 |
| 63 | ≈ 1.16×10⁻⁴ | ≈ 5.4×10⁴ | 低频：转得慢，负责区分远距离位移 |

频率按几何级数从 1 衰减到 $`10^{-4}`$，波长则从约 6 拉开到约 5 万——四个数量级的跨度。这套"粗细搭配的刻度尺"正是第 01 篇正余弦编码的核心思想，RoPE 原样继承了它。

**转过 2π 会发生什么（直觉）。** 当 $`m\theta_i`$ 超过 $`2\pi`$，该维度对就"转了一圈回到起点"：位置 $`m`$ 和位置 $`m + 2\pi/\theta_i`$ 在这一对维度上不可区分。高频维度在长序列上转了很多圈，单看它会"混叠"；但低频维度转得慢，在几万个位置内近似单调不循环，负责兜底远距离的区分。这就是为什么频率必须几何级数拉开：**高频管局部精度，低频管全局不混叠**，两者缺一不可。

一个贴切的类比是**游标卡尺**：主尺刻度稀（低频），读大数、量程大；游标刻度密（高频），读小数、精度高；合起来既大量程又高精度。RoPE 的频率组就是一套"旋转刻度尺"——每个相对位移同时被 $`d/2`$ 把"尺子"量一遍，粗尺定大致远近，细尺定精确差值。注意这只是类比：卡尺的读数是人为组合的，而 RoPE 是把各频率的正余弦**加权求和**进一个打分里（第 2.2 节的公式），"组合"这件事是训练学出来的。

> 结论性质区分：以上"转圈混叠、低频兜底"是**直觉**（来自波长的量级分析）；"几何级数频率组在长程任务上最优"是**需实验验证的结论**——$`10000`$ 这个底数本身就是 Vaswani et al. 2017 凭经验选的，不是从第一性原理推导出来的。

> 结论性质区分："高频对局部敏感、低频覆盖长程"是**直觉**（来自波长的量级分析）；"RoPE 在长程任务上是否真比加法位置编码好"是**需实验验证的结论**（原论文在机器翻译等任务上给出了实证）。

### 3.3 相对距离增大时的衰减（原论文的上界结论）

Su et al. 通过求和估计证明：打分幅值 $`|(R_{\Theta,m}q)^\top(R_{\Theta,n}k)|`$ 存在一个随 $`|m-n|`$ 增大而衰减的上界。直觉是多频率叠加的相位退相干：相对距离拉大时，各频率分量的 $`\cos((m-n)\theta_i)`$ 相位互相错开，求和时正负抵消。论文用的技术是 Abel 求和——把振荡求和改写成"差分 × 部分和"的形式，再对光滑的包络取上界。

这个上界的实践意义（直觉）：训练初期，远距离 token 对之间的打分不会出现极端大的幅值，softmax 不至于被某个远距离位置"劫持"，注意力权重的初始化更温和。这可能是 RoPE 在长序列训练中表现稳定的原因之一——但注意，"可能"二字意味着这是**需实验验证的解释**，不是定理的直接推论。

> 结论性质区分："幅值上界随相对距离衰减"是**严格推导的上界结论**（注意：是上界衰减，不是每个样本的打分都单调衰减——第 4 节的数值例子会直观展示振荡）；"这种衰减带来长程建模优势"是**需实验验证的结论**。

~~~mermaid
flowchart LR
    X["输入 x_m（位置 m）"] --> PAIR["按 (2i, 2i+1) 配对"]
    PAIR --> ROT["每对旋转 m·θ_i 角度"]
    ROT --> QK["得到 R_Θ,m q_m / R_Θ,m k_n"]
    QK --> DOT["内积 → 只依赖 (n−m) 的打分"]
~~~

## 4. 数值示例：亲手算一次旋转打分

取 $`d=4`$（两对），$`\theta_0 = 10000^0 = 1`$，$`\theta_1 = 10000^{-2/4} = 0.01`$。设 query 在位置 $`m=2`$，key 在位置 $`n=5`$（相对位移 $`n-m=3`$）：

```math
q = [\,1,\; 0,\; 2,\; 0\,]^\top, \qquad k = [\,0,\; 1,\; 0,\; 2\,]^\top
```

**方法一：相对公式直接算。** 记 $`\delta_i = 3\theta_i`$：

- 第 0 对：$`(a,b)=(1,0)`$，$`(c,d)=(0,1)`$。$`ac+bd = 0`$，$`bc-ad = 0\cdot 0 - 1\cdot 1 = -1`$。贡献 $`= 0\cdot\cos 3 + (-1)\cdot\sin 3 = -\sin 3 \approx -0.1411`$。
- 第 1 对：$`(a,b)=(2,0)`$，$`(c,d)=(0,2)`$。$`ac+bd = 0`$，$`bc-ad = -4`$。贡献 $`= -4\sin 0.03 \approx -4 \times 0.0300 = -0.1200`$。

打分 $`\approx -0.1411 - 0.1200 = -0.2611`$。

**方法二：显式旋转再内积（交叉验证）。**

- $`R_{2\theta_0}`$ 作用于 $`q`$：第 0 对 $`(1\cdot\cos 2 - 0,\; 1\cdot\sin 2 + 0) = (-0.4161,\; 0.9093)`$；第 1 对 $`2(\cos 0.02,\; \sin 0.02) = (1.9996,\; 0.0400)`$。
- $`R_{5\theta_0}`$ 作用于 $`k`$：第 0 对 $`(0\cdot\cos 5 - 1\cdot\sin 5,\; 0 + 1\cdot\cos 5) = (0.9589,\; 0.2837)`$；第 1 对 $`(0 - 2\sin 0.05,\; 0 + 2\cos 0.05) = (-0.1000,\; 1.9975)`$。

内积：$`(-0.4161)(0.9589) + (0.9093)(0.2837) + (1.9996)(-0.1000) + (0.0400)(1.9975)`$
$`= -0.3991 + 0.2579 - 0.2000 + 0.0799 = -0.2611`$ ✓

两种方法一致（末位差异来自四舍五入）。再做一个检验：把位置平移到 $`m'=0, n'=3`$（相对位移仍是 3），方法一的公式里只出现 $`\delta_i = 3\theta_i`$——打分**完全相同**。这就是"只依赖相对位移"的数值证据。

**相对距离变化时，打分如何变化？** 固定同一对 $`q, k`$，只改变相对位移 $`\delta = n-m`$，用方法一的公式：

| $`\delta = n-m`$ | 第 0 对贡献 $`-\sin\delta`$ | 第 1 对贡献 $`-4\sin(0.01\delta)`$ | 打分 |
|---|---|---|---|
| 0 | 0 | 0 | 0 |
| 3 | −0.1411 | −0.1200 | −0.2611 |
| 5 | +0.9589 | −0.1999 | +0.7590 |

打分随相对位移**振荡**而非单调变化：$`\delta=5`$ 时反而比 $`\delta=0`$ 时大。这正好呼应第 3.3 节的措辞——衰减的是**上界**，单个样本的打分是各频率正余弦的叠加，可正可负。实际注意力里，这个振荡的打分再除以 $`\sqrt{d}`$ 过 softmax，才变成权重。

**打分如何变成权重（小演示）。** 假设某 query 面对三个 key，相对位移分别是 $`\delta = 0, 3, 5`$，打分就是上表的 $`0, -0.2611, 0.7590`$（为演示省略 $`/\sqrt{d}`$ 缩放）。Softmax：

```math
e^{0} = 1.0000, \quad e^{-0.2611} = 0.7702, \quad e^{0.7590} = 2.1359, \quad \text{和} = 3.9061
```

权重 $`= (0.2560,\; 0.1972,\; 0.5468)`$，和为 1 ✓。注意：相对位移 $`5`$ 的 key 拿到了最大权重（0.547）——RoPE 的位置调制**不是**"越远越不重要"的单调惩罚，它只负责把相对位移的信息"写进"打分，**多远算多重要由内容相似度和训练共同决定**。这也是误区 4 的另一面：不要把"上界衰减"脑补成"注意力天然只看局部"。

## 5. 实现：不构造旋转矩阵

实际代码里从不显式构造 $`R_{\Theta,m}`$（那是 $`d \times d`$ 矩阵，浪费）。对位置 $`m`$、向量 $`x`$，第 $`i`$ 对直接算：

```math
\begin{aligned}
y_{2i}   &= x_{2i}\cos(m\theta_i) - x_{2i+1}\sin(m\theta_i) \\
y_{2i+1} &= x_{2i}\sin(m\theta_i) + x_{2i+1}\cos(m\theta_i)
\end{aligned}
```

等价的复数视角：把每对看成复数 $`z_i = x_{2i} + j\,x_{2i+1}`$，则 $`y_i = z_i \cdot e^{j m\theta_i}`$——逐元素复数乘法。工程上 $`\cos(m\theta_i)`$、$`\sin(m\theta_i)`$ 对每个位置预计算一次存表（形状 $`n \times d/2`$），之后全是逐元素乘加，复杂度 $`O(nd)`$，**不引入任何可学习参数**。

最小实现的伪代码（NumPy 风格，交错配对）：

```python
def rope_freqs(d, base=10000.0):
    i = np.arange(d // 2)          # i = 0 .. d/2-1
    return base ** (-2 * i / d)    # theta_i

def apply_rope(x, pos, theta):
    # x: (..., d)，pos: 标量位置 m，theta: (d/2,)
    x1 = x[..., 0::2]              # 每对的第 0 个分量
    x2 = x[..., 1::2]              # 每对的第 1 个分量
    ang = pos * theta              # 每对的旋转角 m*theta_i
    cos_a, sin_a = np.cos(ang), np.sin(ang)
    y = np.empty_like(x)
    y[..., 0::2] = x1 * cos_a - x2 * sin_a
    y[..., 1::2] = x1 * sin_a + x2 * cos_a
    return y
```

**两种配对约定（工程上最常见的坑）。** 上面用的是**交错配对**（interleaved）：$`(x_0,x_1), (x_2,x_3), \dots$`，HuggingFace 的 LLaMA 实现用它。另一种是**半分配对**（half-split，GPT-NeoX / RoFormer 原文）：把向量切成前后两半 $`x = [u; v]`$，第 $`i`$ 对是 $`(u_i, v_i)`$，公式是 $`[u\cos - v\sin;\; u\sin + v\cos]`$。两种只是"谁和谁配对"的约定不同，数学原理完全一样；但**权重不能混用**——用交错约定训练的模型，推理时必须用交错约定加载。

**预计算表与多头的配合。** $`\cos(m\theta_i)`$、$`\sin(m\theta_i)`$ 只与位置 $`m`$ 和频率 $`\theta_i`$ 有关、与输入内容无关，所以对最大序列长 $`N`$ 预计算一张 $`(N, d/2)`$ 的表，训练和推理直接查表。结合第 03 篇的多头注意力：每个头的 Q、K 是各自的子空间投影（维度 $`d_h`$），但旋转规则相同——每个头独立地对自己的 $`(d_h/2)`$ 对维度做同样的旋转，查的是同一张频率表。于是 RoPE 与多头正交：**多头负责"多个子空间各学各的"，RoPE 负责"每个子空间里的相对位置"，互不干扰**。

> 适用条件：旋转作用在 Q、K 的**投影之后**（即 $`W_q x_m`$、$`W_k x_m`$ 上），而不是词向量上；且每个注意力头独立应用同一套规则。

## 6. 常见误区

**误区 1：RoPE 是绝对位置编码，因为它用了绝对位置 $`m`$。**

纠正：输入用的是绝对位置没错，但打分 $`q_m^\top R_{\Theta,n-m} k_n`$ 只依赖相对位移——模型"看到"的位置信息是相对的。原论文标题就叫 RoFormer: Enhanced Transformer with Rotary Position Embedding，实现的是**相对**位置编码。更准确的说法：RoPE 是用绝对位置的输入实现相对位置编码。判断一个位置编码是"绝对"还是"相对"，看的是**打分函数依赖什么**，而不是输入长什么样。

**误区 2：Q、K、V 都要旋转。**

纠正：标准做法只旋转 Q 和 K。位置信息只需要进入**打分**（决定"看哪里"），V 只参与打分定下来之后的加权求和（决定"拿什么内容"），旋转 V 不改变任何打分，纯属多余计算。记住分工：Q、K 管寻址，V 管内容。一个等价的说法：注意力权重 $`a_{mn}`$ 只由旋转后的 Q、K 决定，V 的作用是被这些权重加权——位置信息在"权重确定"这一步已经用完了。

**误区 3：RoPE 增加了模型参数量。**

纠正：没有。$`\cos(m\theta_i)`$、$`\sin(m\theta_i)`$ 是确定性公式预计算的，不是可学习参数。RoPE 的参数增量是 0——这也是它比可学习位置编码更轻量的原因。对比一下：可学习的绝对位置编码要存一张 $`N \times d`$ 的表（$`N`$ 是最大序列长）；Shaw et al. 的相对位置表示要为每个相对偏移存向量，裁剪距离为 $`k`$ 时是 $`(2k+1) \times d`$ 个参数；RoPE 是 0 个。省下来的不只是显存——没有位置参数，就没有"我只在训练长度内见过位置"的参数外推问题（注意：角度本身的外推问题依然存在，见误区 4，两者别混淆）。

**误区 4：RoPE 天生支持外推到任意长的序列。**

纠正：这是**需实验验证的结论**，不能想当然。旋转角度 $`m\theta_i`$ 在训练未见的大 $`m`$ 处会进入模型没见过的角度区间；虽然第 3.3 节的上界衰减给了"远距离打分不会爆炸"的定性保证，但真正的长度外推能力要靠实验检验——后续才有了 Position Interpolation、NTK-aware、YaRN 等一系列外推方法（可作为本系列 12 篇之后的选题）。

**误区 5：打分只依赖相对位移，所以 RoPE 模型是平移不变的。**

纠正：不是。打分公式 $`q_m^\top R_{(n-m)\theta} k_n`$ 里，$`q_m`$ 和 $`k_n`$ 本身是位置 $`m, n`$ 处的内容向量——把整句话平移 10 个位置，内容向量也跟着变了，打分自然不同。"只依赖相对位移"说的是**位置编码部分**的贡献形式，不是模型输出对平移不变。严格表述：给定相同的内容向量，位置编码引入的调制只与相对位移有关。

## 7. 自测题

下面 4 道题覆盖本篇的四个关键点：相对性的证明、相对位移的数值含义、Q/K/V 的分工、多尺度频率的作用。建议先自己动手算一遍再看答案。

**Q1.** 不查资料复述一遍：为什么 $`(R_{m\theta}q)^\top(R_{n\theta}k)`$ 只依赖 $`n-m`$？用到了旋转矩阵的哪几条性质？

<details>
<summary>答案</summary>

$`(R_{m\theta}q)^\top(R_{n\theta}k) = q^\top R_{m\theta}^\top R_{n\theta} k`$。由正交性 $`R_{m\theta}^\top = R(-m\theta)`$（性质 1+2），再由角度可加 $`R(-m\theta)R(n\theta) = R((n-m)\theta)`$（性质 3），得 $`q^\top R_{(n-m)\theta} k`$——$`m, n`$ 只以差的形式出现。
</details>

**Q2.** 第 4 节的例子中，若 query 移到位置 $`m'=10`$、key 移到 $`n'=13`$，打分是多少？为什么不用重算？

<details>
<summary>答案</summary>

仍是约 $`-0.2611`$。相对位移 $`n'-m' = 3`$ 不变，而打分只依赖相对位移（第 2.2 节的严格结论），所以两种位置配置下的打分逐元素相同。
</details>

**Q3.** 为什么 RoPE 只作用于 Q 和 K，不作用于 V？

<details>
<summary>答案</summary>

位置信息的作用是决定注意力**打分**（看哪里），打分只由 Q、K 的内积决定。V 只参与打分确定之后的加权求和（拿什么内容），旋转 V 不改变任何打分——LLaMA 等标准实现都只对 Q、K 应用 RoPE。
</details>

**Q4.** 如果把第 4 节例子里第 1 对的频率也改成 $`\theta_1 = 1`$（和第 0 对一样），会失去什么？

<details>
<summary>答案</summary>

失去多尺度。两对频率相同时旋转周期都是 $`2\pi`$，远距离位移 $`m\theta \bmod 2\pi`$ 会快速循环混叠——模型难以区分"差 3 个位置"和"差 3+2π 个位置"。低频维度（小 $`\theta`$）转得慢，$`m\theta_i`$ 在长程内近似单调不循环，负责远距离的区分。这就是"快慢搭配"的直觉依据。
</details>

## 8. 小结

- **核心思想**：位置编码从"加一个向量"变成"转一个向量"——旋转 Q、K，让相对位移从内积的角度差里自然产生。
- **数学保证**（严格推导）：旋转矩阵的正交性 + 角度可加性 ⟹ $`(R_{m\theta}q)^\top(R_{n\theta}k) = q^\top R_{(n-m)\theta} k`$，打分是相对位移的纯函数；适用条件是同一维度对内 Q、K 共享频率。
- **多尺度**（直觉）：$`\theta_i = 10000^{-2i/d}`$ 几何级数拉开频率，高频定局部精度、低频防长程混叠，如游标卡尺的粗细刻度。
- **实现**：不构造旋转矩阵，查 $`\cos/\sin`$ 预计算表做逐元素乘加，$`O(nd)`$，零新增参数；注意交错配对与半分配对两种约定不可混用。
- **分工**：只旋转 Q、K（管寻址），不旋转 V（管内容）；与多头注意力正交，可叠加使用。
- **边界**（需实验验证）：打分幅值的上界随相对距离衰减，但单个打分振荡不单调；长度外推能力、外推方法的优劣，都要靠实验说话——这也是 RoPE 至今仍有新工作在做的原因。
